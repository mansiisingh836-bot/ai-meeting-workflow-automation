# Business Requirements

## Business Objective

Automate routine post-meeting administrative activities by converting unstructured meeting notes into structured business actions while retaining human review before stakeholder communication.

## Functional Requirements

| ID | Requirement |
|---|---|
| FR-01 | Capture meeting notes |
| FR-02 | Extract structured meeting information |
| FR-03 | Create a follow-up calendar event |
| FR-04 | Create an action-item task |
| FR-05 | Generate a stakeholder email draft |
| FR-06 | Retain human review before sending external communication |
